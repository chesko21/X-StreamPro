# X-StreamPro

Ultimate Streaming Experience.

X-StreamPro is a high-performance IPTV streaming application designed for the best user experience. It supports Xtream Codes API, PiP (Picture-in-Picture) mode, and high-quality live streaming.

## Features
- **Xtream Codes API Integration**: Login with your IPTV service provider.
- **Picture-in-Picture (PiP)**: Watch your favorite channels while using other apps.
- **Premium UI/UX**: Clean, modern, and dark-themed interface.
- **Category Browsing**: Easily find channels by their category (Movies, Sports, News, etc.).
- **Track Selection**: Switch between video qualities and audio tracks.
- **Auto-Update Versioning**: Displays the current application version automatically.

## Installation

3. Build and run on an Android device (API 26+).

## Tech Stack
- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Media Player**: Media3 (ExoPlayer)
- **Networking**: Retrofit & OkHttp
- **Serialization**: Kotlinx Serialization
